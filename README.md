# Ойна да үйрен!

Зияткерлік даму ерекшелігі бар 7–10 жастағы оқушыларға арналған интерактивті қазақша веб-ойын. Ноутбук немесе компьютерде ойналады.

## Ойындар (әрқайсысында 3 деңгей бар)

| Ойын | 1-деңгей | 2-деңгей | 3-деңгей |
|---|---|---|---|
| 🌈 Түстер бағы | 2 түстен таңдау | 3 түстен таңдау | Түсіне қарай затты табу |
| 🐾 Жануарлар мекені | 2 мекеннен таңдау | 3 мекеннен таңдау | Жануар мен мекенді жұптау |
| 🏡 Күн тәртібі | 2 суреттен таңдау | 3 суреттен таңдау | Әрекеттерді ретімен қою |
| 🔎 Заттар әлемі | 2 заттан таңдау | 3 заттан таңдау | Артық затты табу |

## Мүмкіндіктері

- **Кері байланыс:** дұрыс жауапқа жасыл белгі, жұлдызша, мадақ сөз және қуанышты дыбыс беріледі. Қате жауапта нұсқа жұмсақ шайқалып бозарады, «Тағы байқап көр» деген сөз айтылады. 1–2 қатеден кейін дұрыс жауап жарықтанады (қатесіз оқыту).
- **Бейімдеу:** әр ойынның деңгейі, деңгейді автоматты өзгерту, тапсырманы дауыстап оқу (🔊 батырмасы немесе R пернесі), суреттің астындағы жазуды өшіру, үлкен режим, тыныш режим, жоғары контраст, тапсырма саны (3/5/8) және кеңес жиілігі. Уақыт шектеуі жоқ.
- **Марапат:** ойын соңында 1–3 жұлдыз беріледі және жапсырма жинағына жаңа жапсырма қосылады.
- **Нәтижені тіркеу:** «Педагогке» бөлімі көбейту есебімен қорғалған. Онда оқушылардың деңгей бойынша кестесі, әр баланың жеке картасы, нәтиже динамикасы және CSV (Excel) экспорты бар.
- **Қорғау жоспары:** қосымшаның ішінде, «📋 Қорғау жоспары» бөлімінде тұр.

## Іске қосу

Құрастыруды қажет етпейтін статикалық сайт.

```bash
python3 -m http.server 8000
# браузерде http://localhost:8000 ашыңыз
```

Vercel-ге жариялау үшін: репозиторийді Vercel-ге импорттаңыз (Framework: Other, баптаусыз).

## Мазмұнды өзгерту

Барлық тапсырма `js/data.js` файлында тұр. Жаңа түс, жануар, әрекет немесе зат бір жол қосу арқылы енгізіледі.

## Құпиялылық

Нәтижелер тек браузердің `localStorage`-інде сақталады және серверге жіберілмейді.
