# Ойна да үйрен!

Зияткерлік даму ерекшелігі бар **5–6 сынып оқушыларына** (11–13 жас) арналған интерактивті қазақша веб-ойын. Ноутбук немесе компьютерде ойналады. Ойынды кейіпкер-көмекші **Ақбота** жүргізеді, барлық нұсқаулық **таза қазақша нейрондық дауыспен** айтылады.

Сайт: https://oina-uiren.vercel.app

## Ойындар (әрқайсысында 4 деңгей)

| Ойын | 1-деңгей | 2-деңгей | 3-деңгей | 4-деңгей (күрделі) |
|---|---|---|---|---|
| 🔢 Математика | 20-ға дейін қосу, алу, салыстыру | 100-ге дейін есептеу | Мәтінді есептер | Көбейту, бөлу, мәтінді есептер |
| 🕒 Уақыт | Сағатты оқу | Жарты және ширек сағат | Апта күндері, айлар, жыл мезгілдері | Уақыт ұзақтығын есептеу |
| 💰 Ақша және дүкен | Теңгені тану | Ақшаны санау | Сатып алу: ақша жете ме? | Қайтарымды есептеу |
| 📖 Оқу және сөз | Суретке сәйкес сөз | Жетпейтін әріп | Сөйлемді аяқтау | Мәтінді оқып түсіну |
| 🌍 Табиғат және Қазақстан | Жыл мезгілдері | Сыныптау | Даму кезеңдері | Менің Қазақстаным |
| 🛡️ Қауіпсіздік | Бағдаршам мен белгілер | Жедел қызмет нөмірлері | Қауіпсіз бе, қауіпті ме? | Қиын жағдайда не істеймін? |

Сонымен қатар **🤸 Сергіту сәті** бар: қимыл жаттығуы, тыныс алу, көпіршіктер, көз жаттығуы және «Жұбын тап».

## Қазақша дауыс

Ойында айтылатын 620 сөйлем [ISSAI KazakhTTS](https://github.com/IS2AI/Kazakh_TTS) моделімен (Назарбаев университеті, CC BY 4.0; Piper нұсқасы) алдын ала жазылған. Олар `assets/voice/` ішінде тұр. Эмоцияның 4 стилі бар:

| Стиль | Қашан | Дауыс |
|---|---|---|
| `say` | Нұсқаулық, есеп | Анық, сабырлы |
| `cheer` | Мадақ, марапат | Қуанышты, жылдамырақ, жоғарырақ |
| `calm` | Қате болғанда, тыныс алу жаттығуы | Жұмсақ, баяу, қолдаушы |
| `num` | Сандар | Бірқалыпты |

**Мәтінді өзгерткен соң дауысты қайта жасау керек:**

```bash
pip install piper-tts            # ffmpeg те қажет
curl -LO https://github.com/rhasspy/piper/releases/download/v0.0.2/voice-kk-issai-high.tar.gz && tar xzf voice-kk-issai-high.tar.gz
node tools/collect-voice.js      # барлық сөйлемді жинайды → tools/phrases.json
python tools/build-voice.py --model kk-issai-high.onnx --speaker 3
```

Тек жаңа сөйлемдер жазылады, ескілері сақталады.

Дауыс ерекше білім беруді қажет ететін оқушыларға арналғандықтан әдейі **баяу** жазылған (модельдің қалыпты жылдамдығынан 1,2–1,5 есе баяу), сөйлемдердің арасында үзіліс бар. Баптауда «Дауыс жылдамдығы» параметрімен оны тағы баяулатуға болады.

## Мүмкіндіктері

- **Кері байланыс:** дұрыс жауапқа жасыл белгі, жұлдызша және қуанышты мадақ беріледі. Қате жауапта нұсқа бозарады, жұмсақ дауыспен қолдау сөзі айтылады. 1–2 қатеден кейін дұрыс жауап жарықтанады.
- **Бейімдеу:** деңгей (1–4) және оны автоматты өзгерту, дауыс және оның жылдамдығы, жазуды жасыру, үлкен режим, тыныш режим, жоғары контраст, тапсырма саны, кеңес жиілігі, сергіту уақыты.
- **Нәтижені тіркеу:** «Педагогке» бөлімінде деңгей бойынша кесте, жеке карта, динамика және CSV (Excel) экспорты бар.
- **Қорғау жоспары** қосымшаның ішінде тұр. Жетілдіру сценарийі `docs/zhetildiru-scenariy.md` файлында.

## Іске қосу

```bash
python3 -m http.server 8000      # http://localhost:8000
```

Мазмұн `js/data.js` файлында, тапсырма генераторлары `js/engine.js` файлында. Нәтижелер тек браузердің `localStorage`-інде сақталады.
