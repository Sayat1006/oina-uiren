# Ойна да үйрен!

Зияткерлік даму ерекшелігі бар **5–6 сынып оқушыларына** (11–13 жас) арналған интерактивті қазақша веб-ойын. Ноутбук немесе компьютерде ойналады. Ойынды кейіпкер-көмекші **Ақбота** жүргізеді, әр әрекетке жұмсақ **дыбыс эффектісі** бар.

Сайт: https://oina-uiren.vercel.app

## Дыбыс эффектілері

Ойында сөйлейтін дауыс жоқ: тапсырма экранда жазумен және суретпен беріледі. Оның орнына әр әрекетке жұмсақ дыбыс эффектісі бар. Дыбыстар файлсыз, браузердің Web Audio құралымен (`js/engine.js` → `SFX`) жасалады, сондықтан сайт жеңіл әрі интернет баяу болса да тез ашылады.

| Әрекет | Дыбыс |
|---|---|
| Жаңа тапсырма | Жеңіл «ушш» және бір қоңырау |
| Дұрыс жауап | Үш нотадан тұратын қуанышты қоңырау |
| Бөлігі дұрыс (сәйкестендіру, топқа бөлу) | Қысқа екі нота; карточка қорапқа «түседі» |
| Ретке қою | Әр дұрыс қадам сайын нота жоғарылай береді |
| Қате жауап | Ащы емес, жұмсақ «бұп-бұп» |
| Кеңес жарқырады | Жылтыр дыбыс |
| Сандық пернетақта | Әр пернеге шерту, өшіруге төмен дыбыс |
| Ойын соңы | Әуен, әр жұлдызға бір дыбыс, жаңа деңгей ашылса — салтанатты әуен |
| Сергіту сәті | Қимылға ырғақ, дем алуда баяу көтерілетін, дем шығаруда төмендейтін дыбыс, көпіршік жарылғанда «тырс» |

Тыныш режимде дыбыс ақырынырақ болады. Баптаудағы «Дыбыс эффектілері» арқылы толық өшіруге болады.

## Мүмкіндіктері

- **Жауап түрлері:** нұсқаны таңдау, топқа бөлу, ретке қою, сәйкестендіру және 4-деңгейде жауапты экрандағы **сандық пернетақтамен** өзі жазу.
- **Мотивация:** жұлдыздар, күнделікті мақсат шеңбері (күніне 3 ойын), әр ойынның ең жақсы нәтижесі мен деңгей жолағы. Бәсекелік рейтинг жоқ.
- **Кері байланыс:** дұрыс жауапқа жасыл белгі, жұлдызша және қуанышты мадақ беріледі. Қате жауапта нұсқа бозарады, жұмсақ дыбыс пен қолдау сөзі шығады. 1–2 қатеден кейін дұрыс жауап жарықтанады.
- **Бейімдеу:** деңгей (1–4) және оны автоматты өзгерту, дыбыс эффектілері, жазуды жасыру, үлкен режим, тыныш режим, жоғары контраст, тапсырма саны, кеңес жиілігі, сергіту уақыты.
- **Нәтижені тіркеу:** «Педагогке» бөлімінде деңгей бойынша кесте, жеке карта, динамика және CSV (Excel) экспорты бар.
- **Қорғау жоспары** қосымшаның ішінде тұр. Жетілдіру сценарийі `docs/zhetildiru-scenariy.md` файлында.

## Іске қосу

```bash
python3 -m http.server 8000      # http://localhost:8000
```

Мазмұн `js/data.js` файлында, тапсырма генераторлары `js/engine.js` файлында. Нәтижелер тек браузердің `localStorage`-інде сақталады.
